# ADR-0001：通过本地网关兼容游戏前端

## 决策

使用本地 HTTP 网关承接游戏前端原有接口。游戏端仍负责展示和交互，信件、MIDI、歌单和媒体由本地服务提供。

## 原因

- 能复用 OliviaSoul 已验证的前端补丁思路。
- 不把 UI 逻辑和模型、音频、视频实现耦合在一起。
- 便于保留原规则，同时提供高级用户开关。
- 未来可以把网关替换成打包后的桌面服务，而不改变领域模块。

## 约束

只实现已观察到的客户端契约；未知接口返回明确错误，不伪造官方服务数据。

## 2026-09-11 验收回归

本地网关继续承接 Steam `0.0.9.627` 的信件、MIDI、歌单、媒体和视频资产请求；预设歌单字段兼容与合成视频回信播放已在用户实机验收中确认。网关成功响应和日志仍只是辅助证据，最终声音、画面和交互结论以用户观察为准。
