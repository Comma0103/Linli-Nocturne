# 需求基线

## 必须交付

1. 游戏内写信入口和本地文字回信。
2. 默认每日最多 3 封、最短延迟 5 分钟，并提供关闭限制的开关。
3. 外部模型 API、本地模型和无模型降级路径。
4. SQLite 信件、记忆、队列和失败重试。
5. MIDI 上传、校验、解析、延音踏板、音频生成和本地曲库。
6. 文字、视频、音频和未来 3D 演奏使用统一媒体任务模型。
7. 已有 MP4 视频回信导入、播放、替换、删除和备份。
8. 面向普通用户的安装器、配置向导、模型选择、日志、备份和恢复。

## 最终目标

- 规则化和模型辅助的即兴 MIDI 创作。
- 可替换的 AudioRenderer、VideoRenderer、Future3DRenderer。
- MIDI 到林离 3D 演奏视频的可扩展接口。
- 手指、音符、镜头、动作和音色的同步控制。
- 成熟后公开源代码、人格资料和样例信件。

## 边界

不分发米哈游原始资源、修改后的二进制文件、用户隐私数据和 API Key；不绕过 DRM。
