# Phase 1：本地领域闭环

## 已完成

- SQLite 信件表、状态和索引。
- 原规则：默认每日最多 3 封，延迟 5 分钟。
- 高级 bypass 开关：取消额度和延迟限制。
- `ModelAdapter` 与离线降级 provider。
- 本地 HTTP 网关：健康检查、写信、列表、详情、未读数和处理队列。
- RenderJob、MIDI 时间轴清单和未来 3D 轨道扩展点。

## 当前边界

这一阶段的回信处理器是串行最小闭环，尚未加入记忆检索、失败重试、视频附件和游戏资源补丁。下一阶段会先增加 SQLite 迁移、任务重试和兼容游戏前端的字段映射，再接入 MIDI 文件解析和音频 renderer。
