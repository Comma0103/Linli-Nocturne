# Phase 1：本地领域闭环

本阶段的目标是建立可以独立运行、可以测试、可以被游戏网关调用的最小本地闭环，不要求最终产品的全部信件体验和媒体能力在本阶段完成。

## 已完成

- SQLite 信件表、状态和索引。
- 原规则：默认每日最多 3 封，延迟 5 分钟。
- 高级 bypass 开关：取消额度和延迟限制。
- `ModelAdapter` 与离线降级 provider。
- 本地 HTTP 网关：健康检查、写信、列表、详情、未读数和处理队列。
- RenderJob、MIDI 时间轴清单和未来 3D 轨道扩展点。

## 本阶段边界（已完成，不是遗留缺陷）

以下能力当时被明确放到后续阶段，因此不属于 Phase 1 的未完成项：

- 记忆检索和长期记忆库；
- 失败重试和更完整的异步任务调度；
- 外部模型 API、本地模型运行时和模型选择界面；
- 视频回信导入、播放、替换和删除；
- 游戏资源补丁、安装器和真实游戏启动验证。

其中 MIDI 解析、延音踏板、音频渲染和本地歌单已经在 Phase 1 音乐基础中完成；持久化 MIDI 任务和前端兼容补丁则在 Phase 2 中继续增强。
